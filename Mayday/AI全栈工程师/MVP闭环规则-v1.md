# MVP 闭环规则 v1

> **依据**：`产品经理/协作纪要/001-废弃时间线功能模块.md`
> **协作**：产品定优先级与验收；工程定模型与落地切片  
> **继承**：旧 Mayday 扫描/播放/歌单；**废弃**时间线/时间隧道  

---

## 0. MVP 目标一句话

让可识别用户完成：发现歌曲 → 播放 → 歌单沉淀（登录可选增强）。

---

## 1. 闭环定义（必须全部可走通）

进入站点 → 曲库/搜索 → 播放 → 连续听 → 歌单 →（登录）个人沉淀

**非目标**：时间线 / 时间隧道；复杂推荐；正版版权体系

---

## 2. 优先级与 MVP 范围

P0：扫描、曲库、播放、歌单  
P1：用户体系完善  
P2：会员商业化（订单骨架 + mock 履约已通；Stripe 可选；微信/支付宝待后续）  

---

## 3. 逻辑数据模型（最小）

User / Song / Album / Playlist / PlaylistSong  
（Tour / Quote / Image 可暂留库表，无时间线出口）
