# 选型记录 003 · 第一刀应用壳

## 1. 现状摸底

- 布局：顶栏水平 nav + 居中主内容 + `#musicPlayer` 底栏（无侧栏）。
- 播放：队列/模式/localStorage/软导航已较强；进度条 CSS 有、收起条 DOM 弱。
- 登录：`login_view` / `register` / `logout` 直接 `redirect('index')`。
- 歌单：可用但未按用户隔离。

## 2. 选型与偏差

| 计划示例 | 本刀选择 | 原因 |
|----------|----------|------|
| Next.js + Tailwind + shadcn | **继续 Django 模板改 `base.html`** | 衔接优先、一刀可验收 |
| Apple 顶栏播放器 | **Spotify 式底栏** | 已有 `#musicPlayer`，改动最小 |
| Vercel | 不迁 | 非本刀范围 |
| Linear | 仅密度：侧栏窄、分组标签克制 | 不引入 Issue UI |

## 3. 本刀切片

1. CSS Grid 应用壳 + 侧栏导航（替换顶栏主导航）。
2. 底栏收起条挂进度控件，接线既有 `audio` 时间更新。
3. 恢复 Django 登录/注册/退出视图；侧栏显示登录态。
4. 主区内容模板基本不动。

## 4. 开放问题 / 默认假设

- **默认**：登录后暂不改歌单归属逻辑（仍可能全局可见）；下一刀再做 per-user。
- **默认**：音量滑条放到下一体验刀，本刀只补进度。
- 移动端：侧栏可收为顶栏图标抽屉（已做窄屏抽屉开关）。

## 5. 本刀交付回写

- `templates/mayday_app/base.html`：暗色三区壳 + 侧栏 + 底栏进度条。
- `mayday_app/views.py`：恢复 login / register / logout。
- 未迁 Next / Vercel；播放器队列核心未动。
