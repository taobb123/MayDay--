# 选型记录 001 · 废弃时间线功能模块

## 1. 现状摸底

- 聚合实现：`mayday_app/timeline.py`（`TimelineRepository`）
- API：`TimelineView` + `GET /api/timeline/`
- 序列化/分页：`TimelineItemSerializer`、`TimelinePagination`
- 接口：`TimelineRepositoryInterface`（及历史上的 `TimeTunnelItem` 抽象）
- UI：`base.html` 导航「时间隧道」、相关 CSS；`index` 已不再渲染时间线区块

## 2. 偏差说明

相对《初步的项目计划》中的「推荐歌单/发现」路径：本刀只执行产品硬约束「废弃时间线」，不顺带引入新发现页。

## 3. 本刀切片

1. 删除 `timeline.py`；去掉 URL / View / Serializer / Pagination / Interface。
2. 导航与 slogan 去时间隧道文案；清理专用 CSS。
3. **保留** Album/Song/Tour/Quote/Image 模型与现有 ViewSet（曲库与后台仍可用）；Tour/Quote/Image 不再经时间线聚合出口。
4. `TimeTunnelItem` 暂留为领域接口父类（模型方法仍在），产品层不再承诺「时间隧道」功能；后续可再解耦。

## 4. 开放问题 / 默认假设

- **默认**：不删 Tour/Quote/Image 表与 Admin，避免误伤已有数据。
- 若产品下一步要求「连巡回/言论/相册产品面一并下线」，另开纪要。
