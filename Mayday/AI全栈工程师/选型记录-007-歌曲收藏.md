# 选型记录 007 · 歌曲收藏

## 1. 现状摸底

- 无 Favorite 模型/API/UI；仅有歌单。

## 2. 选型

| 项 | 选择 | 原因 |
|----|------|------|
| 模型 | `Favorite(user, song)` + unique_together | 简单、可索引 |
| API | `GET/POST toggle` + `DELETE` 可选合并为 toggle | 前端心形一次调用 |
| UI | 首页心形 + `/favorites/` 页 | 最小可验收 |

## 3. 本刀切片

1. 模型 + migration + admin  
2. API + 页面 + 侧栏  
3. 首页/搜索结果心形按钮  

## 4. 默认假设

- 本刀不做收藏数量会员门控（与歌单上限区分）。  
- 底栏播放器心形留待体验刀。

## 5. 本刀交付回写

- 模型 `Favorite` + migration `0007`。
- 页 `/favorites/`；API `list` / `ids` / `toggle`。
- 首页与搜索结果心形；侧栏「我喜欢的」。
