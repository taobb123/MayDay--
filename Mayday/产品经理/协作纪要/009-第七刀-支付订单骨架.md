# 009 · 第七刀切片：支付订单骨架

> 双角色沟通纪要 · 产品经理主导  
> 前置：006 会员骨架（mock 升级）  
> 对齐：计划中的 Stripe / 国内支付 — **本刀先接 Stripe 可选，默认 mock 降级**

## 1. 目标

会员开通走**订单闭环**：创建订单 →（Stripe Checkout 或演示确认）→ 履约开通会员。  
无支付密钥时自动降级演示，**禁止把密钥写进仓库**。

## 2. 范围

| 做 | 暂不做 |
|---|---|
| `MembershipOrder` 订单模型（状态：pending/paid/failed/canceled） | 微信/支付宝正式接入 |
| 结账 API：按配置走 Stripe 或 mock | 完整发票/退款/订阅自动续费 |
| Stripe Webhook 履约入口（验签，密钥来自环境变量） | 运营对账后台大而全 |
| 会员页 CTA 改为「开通会员」并展示当前支付模式 | 多套餐 SKU 矩阵 |

## 3. 关键路径

```
登录 → 会员页 → 开通会员
 → mock：生成已支付订单并开通 30 天
 → stripe（已配置密钥）：跳转 Checkout → 回来后会员生效（Webhook/成功页履约）
 → 订单可在 Admin 查看
```

## 4. 硬约束

- 密钥仅环境变量：`STRIPE_SECRET_KEY` / `STRIPE_WEBHOOK_SECRET` 等。
- `PAYMENT_PROVIDER=mock|stripe`；stripe 缺密钥时须降级并提示，不得 500 裸崩。
- 同一订单不可重复履约开通。
- 未登录不可下单。

## 5. 验收标准

- [x] mock 下开通产生 `paid` 订单且会员生效。
- [x] 未登录结账 → 401。
- [x] 状态 API / 会员页能区分支付模式文案。
- [x] Stripe Webhook 路由存在（GET→405）；无密钥时 mock 路径可用。

冒烟：checkout mock + order paid；success 200；anon 401。
