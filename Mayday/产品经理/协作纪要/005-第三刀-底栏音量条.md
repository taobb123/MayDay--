# 005 · 第三刀切片：底栏音量条

> 双角色沟通纪要 · 产品经理主导  
> 前置：003 应用壳（进度已有）· 004 歌单隔离  
> 依据：技术选项范围体验底线「进度、上一首/下一首、**音量**、队列」

## 1. 目标

底栏常驻播放器具备**可调节音量**（含静音切换），并在切页/刷新后尽量保持音量偏好。

## 2. 范围

| 做 | 暂不做 |
|---|---|
| 底栏音量滑条 + 静音按钮 | 设备投放 / 均衡器 / 响度标准化 |
| `audio.volume` 绑定；偏好写入 localStorage（随 playerState 或独立键） | 会员、UI 大改、Next/Vercel |
| 窄屏可缩短滑条，不挡主控按钮 | 系统级系统音量（仅页内） |

## 3. 关键路径

```
播放任意曲 → 拖动音量条 → 音量即时变化
 → 点静音 → 无声；再点恢复原音量
 → 刷新或软跳转后音量偏好仍在
```

## 4. 硬约束

- 不破坏既有进度条、队列、播放模式、localStorage 恢复逻辑。
- 默认音量合理（建议 0.8），禁止默认静音导致「以为播不了」。
- 控件须在 `#musicPlayer` 激活时可见。

## 5. 验收标准

- [x] 底栏可见音量滑条与静音入口（`#volumeSlider` / `#volumeMuteBtn`）。
- [x] 拖动调用 `setVolume` → `audio.volume`（0–1）。
- [x] 静音切换可逆（`toggleMute` + `volumeBeforeMute`）。
- [x] 偏好写入 `playerVolume` 与 `playerState.volume`；启动 `initPlayerVolume` / 恢复态覆盖。
