# 007 · 第五刀切片：歌曲收藏

> 双角色沟通纪要 · 产品经理主导  
> 前置：004 登录隔离 · 006 会员骨架  
> 对齐 MVP 链：播放 → **收藏** → 歌单

## 1. 目标

登录用户可将歌曲加入「我喜欢的」，并在独立列表中浏览、取消收藏、一键播放。

## 2. 范围

| 做 | 暂不做 |
|---|---|
| Favorite 模型（user+song 唯一） | 真实支付；分享收藏夹 |
| 列表页 `/favorites/` + 侧栏入口 | 收藏夹多级分类 |
| API：列表 / 切换收藏（toggle） | 社交动态 |
| 首页歌曲行收藏心形（需登录，未登录引导） | 播放器底栏心形（可下刀） |
| 收藏列表可播放 / 加入歌单（复用既有） | 会员收藏上限（本刀不门控，权益文案可预告） |

## 3. 关键路径

```
登录 → 首页点♡ → 收藏成功
 → 侧栏「我喜欢的」→ 看到该曲 → 可播放 / 取消收藏
 → 未登录点♡ → 引导登录（带 next）
```

## 4. 硬约束

- 收藏读写须登录；禁止操作他人数据。
- 同一用户同一歌曲不可重复收藏。
- 删除歌曲时级联清理收藏（FK CASCADE）。

## 5. 验收标准

- [x] 登录可 toggle 收藏；列表 API 仅返回本人。
- [x] `/favorites/` 需登录；侧栏有入口。
- [x] 未登录 toggle → 401；页 → 302。
- [x] 取消收藏后列表不再出现。

冒烟：toggle 201/200；`/api/favorites/list/` count；匿名 302/401。
