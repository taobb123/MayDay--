# 003 · 第一刀切片：应用壳（侧栏 + 主区 + 底栏播放器）

> 双角色沟通纪要 · 产品经理主导  
> 前置：001 废弃时间线 · 002 技术选项范围

## 1. 目标

让站点**一眼可识别为音乐产品应用壳**（对齐 Spotify/Apple IA 底线），并在壳上跑通演示链：

**侧栏进入 → 搜索/点选 → 播放 → 连续播 → 侧栏进歌单**。

本刀解决的是「壳与入口」，不是换栈、不是会员。

## 2. 范围

| 做 | 暂不做 |
|---|---|
| `base.html` 三区壳：左导航 · 主内容滚动 · 底栏常驻播放器 | Next.js / Vercel 迁站 |
| 侧栏链到：首页、歌曲/搜索、我的歌单、随机歌单；登录入口可见 | 像素级复刻 Apple/Spotify；品牌 Logo/文案照搬 |
| 底栏补**可见进度条**（体验底线中的进度） | 完整音量条、全屏 Now Playing、推荐算法 |
| 恢复登录/退出可用（可先不做歌单按用户隔离） | 用户隔离歌单、会员、支付 |
| 保持扫描/搜索/播放队列/歌单 CRUD 既有能力 | 时间线回潮 |

## 3. 关键路径

```
打开站点（暗色应用壳）
 → 侧栏「首页」看到曲库
 → 搜索或点播放
 → 底栏常驻播放，可下一首/队列
 → 侧栏「我的歌单」管理/再播
 → 侧栏「登录」（可进表单并完成登录或看到已登录态）
```

## 4. 硬约束

- 须满足技术选项范围体验底线：**三区结构、暗色、全局播放器、切页不丢播**。
- **底栏播放器**为本刀默认（Spotify 参照）；不强制顶栏播放器。
- 衔接优先：不重写播放器核心逻辑（队列/模式/localStorage）。
- 禁止时间线入口与叙事。

## 5. 验收标准

- [x] 任意页面可见：左侧栏 + 主区 + 底栏播放器（有歌时）。
- [x] 侧栏可到首页、歌单；无「时间隧道」。
- [x] 搜一首 → 播放 → 结束后可自动下一首（既有能力保留，未改队列核心）。
- [x] 底栏有可拖拽进度条（`#playerProgress`）。
- [x] 登录页可打开（200）；侧栏含登录/退出入口（歌单按用户过滤不在本刀）。
