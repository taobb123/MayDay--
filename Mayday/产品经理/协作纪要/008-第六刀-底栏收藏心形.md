# 008 · 第六刀切片：底栏播放器收藏心形

> 双角色沟通纪要 · 产品经理主导  
> 前置：007 歌曲收藏；对齐 Spotify/Apple 常驻播放器收藏入口

## 1. 目标

在**全局底栏播放器**上可直接收藏/取消当前曲，状态与首页心形、「我喜欢的」一致。

## 2. 范围

| 做 | 暂不做 |
|---|---|
| 底栏心形按钮（绑定当前 `currentSongId`） | 真实支付 |
| 切歌/恢复播放后同步收藏态 | 收藏动画大改 |
| 未登录点击引导登录 | 新 API（复用 toggle/ids） |
| 与列表心形状态互相同步 | 会员收藏门控 |

## 3. 关键路径

```
播放任意曲 → 底栏点♡ → 收藏
 → 侧栏「我喜欢的」可见
 → 再点♡ 取消；首页同行心形同步
 → 未登录点♡ → 引导登录
```

## 4. 硬约束

- 无当前曲时心形禁用或无操作。
- 复用既有 `/api/favorites/toggle/`，不另造接口。
- 不破坏进度/音量/队列。

## 5. 验收标准

- [x] 底栏可见收藏按钮，有当前曲时可 toggle。
- [x] 复用 `/api/favorites/toggle/`；切歌经 `updatePlayerUI` → `syncPlayerFavoriteButton`。
- [x] 启动已登录预拉 `ids`；与列表心形同步。
- [x] 页面含 `playerFavoriteBtn` / `togglePlayerFavorite` / `syncPlayerFavoriteButton`。

冒烟：首页 200，上述标识均存在。
