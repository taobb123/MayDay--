# 协作模式（复用第一次成功模式）

后续每个**新需求模块**按同一节奏推进，以「用户系统」样板为范例。

## 固定流程

```
1. 产品经理
   目标 / 做与不做 / 关键路径 / 硬约束 / 验收标准
        ↓
2. 双角色沟通纪要（产品经理/协作纪要/00N-….md）
   + 工程选型摘要（AI全栈工程师/选型记录-00N.md）
        ↓
3. 确认共识与默认假设
        ↓
4. AI全栈工程师落地最小可验收切片（样板优先 mock/壳）
        ↓
5. 对照验收清单；偏差回写选型记录
```

## 纪要必备五段（产品输入模板）

1. **目标**  
2. **范围**（做 / 暂不做）  
3. **关键路径**  
4. **硬约束**  
5. **验收标准**

## 工程回应必备

1. 现状摸底  
2. 选型与相对计划示例的偏差说明  
3. 下一刀最小切片  
4. 开放问题 + 默认假设  

## 样板模块

（衔接 Mayday 旧项目 → 商业闭环；时间线已废弃，见纪要 001）

## 业务闭环阶段

发现/搜索 → 播放 → 收藏 → 歌单 → 登录 → 会员/订单（mock，Stripe 可选）  
**非目标**：时间线 / 时间隧道；微信支付宝（待开刀）
